# S02 — native headless evidence question

C02/C03/C08/C09 subsets. One question explicitly selects a registered text
source/version/byte range; Agent calls configured Sources/Inference executables
through their public JSON contract, assembles an untrusted-evidence prompt,
counts exactly that request, enforces a reserved-output budget, returns a fake
answer with pinned citations. No fake semantic-quality claim. C11 is not complete
through this short-lived CLI proof; no persistent service/admission claim.

Agent owns question policy and product prompts; Inference owns fake provider
capability/token/generation rules; Sources owns source bytes and literal evidence.
Owned files: native sources/headers/tests/Makefiles/contracts in Agent/Inference;
Sources uses its existing host configuration flags in that public argv array.
The JSON parser is a local mechanical transport primitive copy, not shared policy
or a fifth business package. Every folder builds without sibling private files.

Host-configured public argv JSON arrays `--sources-command` and
`--inference-command` are passed directly to execvp, never a shell. Requests cannot
choose commands, state paths or host roots. Child responses <=1 MiB and deadlines
10 seconds. Agent input <=16 KiB; explicit evidence <=64 KiB; question <=2 KiB;
fake provider context 128 KiB JSON/UTF-8-byte tokens; output reservation 256.
All calls use the exact same prompt for counting and generation, pinned provider.

Acceptance: actual separate native processes, selected text in exact prompt,
source/version/range citations preserved, no hidden reader calls, stale/invalid
read fails before model; provider/version/budget mismatch typed; malformed/error/
oversized/slow child handled and owned process group reaped. C transport tests
with hostile helpers and shell integration using configured external artifact
paths. Run make test/sanitize/release and independent clean copies.

Excludes PDF/real models/persistence/effects/App and production retirement.
Preparatory until S03-S06 and all broad gates. Follow ordered sequence afterward.
