# S06a — native opaque last-good sessions

Implement owner/provider/context-bound opaque session create/lookup and optional
generation binding in the existing Inference dispatch, fake and native. Native
SQLite cache at configured private Inference state; no Agent/source fields. One
work lock authorizes busy recovery. Expected session revision prevents mixed turns;
commit last-good prompt/result/revision only after successful provider response.
Failed/interrupted work clears busy while preserving previous checkpoint. No
claim that semantic cached prompt is a binary KV checkpoint or model residency.

Native session limits128 handles,128KiB decoded prompt,64KiB answer,8MiB aggregate
cache,16MiB SQLite; refuse without evicting pinned handles. Opaque IDs random48hex,
owner from trusted host config (public authentication is later S13). Descriptor
advertises sessions only when private state configured. Plain stateless fake
calls still work; no HTTP/model requirement. SQLite is declared native dependency.

Public session_create(provider_id),session_get(session_id), generate optional
session_id+expected_session_revision together; result public session_id/revision.
Count/generation policy remains one path; no provider-name branches in Agent.
Native C controlled failure/stale/foreign/provider/restart/busy/quota tests, sanitizer
and standalone build/release; native model roundtrip. Then S06b wires Agent public
refs/budget/compaction and actual hot/cold workflows from parent S06 specification.
No Python. This bounded patch is not full C04/C08 completion.
