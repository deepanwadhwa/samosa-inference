# S12b — scoped cancellable inference operations

Preparatory C04/C11 after S12a: count/generate may carry operation_id. Inference
owns a bounded owner-scoped operation history with normalized request identity,
exact saved responses, running/cancelled/interrupted status and independent kernel
worker leases. Public operation_get/operation_cancel authenticate the configured
owner and target that operation alone. Untracked compatibility requests retain
bounded admission; the assembled App will submit tracked model operations.

Owner: Inference operations.c/h, public dispatcher, FIFO cancellation polling and
native curl progress callback. Private operation state cannot become conversation
truth. Maximum128 retained operations,8MiB result bytes,16MiB SQLite; no eviction.
Each operation has a private cancellation marker descriptor and own worker lease.
Cancellation of queued work removes only its ticket; active cancellation closes
only its curl transfer. A cancelled/failed generation preserves last-good session.
Cancellation is a request and can race completed work; get reports actual status.
Kernel proof marks a dead worker interrupted; no automatic model-request replay.

Included native owner/retry/conflict, queued/active cancel, dead-worker recovery,
quota/offline cached result tests and controlled native HTTP isolation tests.
Excluded model installation/readiness/residency, streaming, App, legacy retirement
and whole C04/C11 completion. No Python or sibling source dependency.
Completion requires focused/full sanitizers plus independent Mac/Linux execution.
Focused commands: `make test-admission test-operations test-native`.
Full qualification: `make test sanitize test-native sanitize-native release`.
Descriptor checks cover default/unconfigured and configured FIFO limits plus
owner-gated sessions/operations/cancellation. Release includes text-v1,
admission-v1 and operations-v1 contracts. This remains preparatory until the
assembled product quality/transport gates pass.
