# S04 — optional real native text provider

C03/C04/C08 subsets. Native C Inference adapter uses published llama-server HTTP
API through system libcurl. Optional build target; fake/default build remains
libc-only and Sources text has no model/HTTP dependencies. No Python anywhere.
Host config pins endpoint/provider/context/admission directory. User request
cannot choose model paths, endpoints or replace provider ID.

Exact request: wrap Agent's product prompt as one user message using the engine's
apply-template (thinking disabled), tokenize that rendered string using engine
rules, count actual token IDs. Generation sends exactly that token array to
completion and enforces context+reserved output. Provider owns all rendering and
tokenizer details; no Agent model-name branch. Report total input tokens and real
processed prompt tokens separately, output usage and errors.

One native active operation per configured admission directory; zero queued,
nonblocking busy refusal, process lock releases on exit. This is bounded basic
admission only; fair queue/host residency/cancellation/session gates remain open.
HTTP responses <=1 MiB, connect2 seconds, request60 seconds; endpoint localhost
HTTP/HTTPS only for this subset, no redirects or request-chosen URLs. CLI deadline
for assembled calls will be explicitly bounded. Each component remains independent.

Acceptance: C controlled HTTP server tests template/token/count identity,
provider mismatch, budgets, oversized/error responses and one-slot busy; real
configured existing llama native engine quality smoke and Agent selected text /
PDF question output. Native C and shell tests, no engine-private state/readers.
make test/sanitize/release; optional make native/test-native with declared libcurl
and configured endpoint. Independent copies repeat focused qualification.

Preparatory: not all C03/C04/C08; no streaming/install/multimodal/residency/cache
or full service claims. Then S05/S06 durable conversation and context qualification.

Provider pin refinement: require host-configured model alias; before preparing
any native work, query public /props and require that alias and exact configured
context. Refuse provider_changed before tokenization/generation when they differ.
An alias is not a verified artifact checksum: installation/engine-version digest
qualification remains in C03/C04, explicitly open. Controlled server tests include
changed alias; native QA uses the actual existing engine alias from public props.
